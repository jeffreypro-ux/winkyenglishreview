如何更新网站内容？

① 添加一节新课：打开 index.html，搜索定位到 ★★★ 新课程粘贴在这一行的上方 ★★★，复制一节模板粘贴到上方，改内容保存即可：

{
  id: 11,
  date: "2026-09-20",
  title: "第十一课：标题",
  subtitle: "Mike 老师 · 口语实战",
  intro: "本课一句话总结。",
  sections: [
    { h: "一、核心句型", type: "list", items: [
      "<span class='en'>English sentence.</span> 中文。" ] },
    { h: "二、对话", type: "dialog", lines: [
      ["Winky", "What did you do?"],
      ["Mike", "I stayed at home."] ] },
    { h: "课后作业", type: "homework", text: "复述并录音。" }
  ]
}

板块类型说明：list 知识点列表 / table 中英对照表 / dialog 对话 / tip 老师提醒 / homework 作业

② 添加单词：在 WORDS 数据区同样格式加一行：

{ w:"envelope", p:"/ˈenvələʊp/", m:"n. 信封", e:"Grab the red envelope!" }

③ 想用真人录音/mp3？把 mp3 传到仓库 audio/ 文件夹，然后在数据里加 audio:"audio/xxx.mp3"，网站会优先播放 mp3，没有就自动用内置女声。
